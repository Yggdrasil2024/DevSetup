# Fonctionnement des ordinateur

Un ordinateur est une machine électronique programmable qui traite des données et exécute des opérations logiques et arithmétiques. Il permet de naviguer sur Internet, rédiger des documents ou jouer à des jeux grâce à la combinaison de deux éléments indissociables : le matériel physique et les logiciels. dans le deroulé notre presentation nous engloberons les ordinateurs peronnelles mais aussi les serveurs et autres. dans la suite de ces note nous parlerons un peut plus en detail du fonctionnement des ordinateurs.

# Subdivision

## 1. Hardware
 le hard il est la partie physique et tangible de l'ordinateur il contient tous les composants physiques necessaire pour le fonctionnement de la machine generalement branché à un circuit imprimé principale appelé carte mère. parmis les composants de l'hardware on peut citer la carte mère, le processeurs, les cartes d'extensions, la carte graphique, etc.
 sur la plupart des ordinateurs le hardware vient géneralement de plus fabiriquant differents specialisé comme Nvidia pour les cartes graphique, MSI pour les cartes mères ou encore Intel pour les processeurs plutôt que d'un seul fabriquant à l'exception d'entreprises comme Apple qui gerent leur materiel de  bout en bout. mais le hardware seul est inutile, un seul rassemblement de composant sans rien pour les animés. c'est à ce moment là qu'intervient le software.

 ## 2. Software
 c'est la partie immatérielle, logique de l'ordinateur, il est l'équivalent de ce qu'est l'âme pour un humain, si on devait faire un parallèle. il permet de faire fonctionner fonctionner l'ordinateur et nous permet de reellement travailler avec.

 ### les systemes d'exploitations

 il sont le premiers logiciel qui est installé sur un ordinateur. il assure le fonctionnement de cette derniere en faisant d'abords fonctionner le hardware en synergie mais aussi en gerant et en allouant les ressources aux differentes applications installée pas les utilisateurs.
 il sont construits autour d'un noyau et fournissent aussi une interfaces pour les applications et les utilisateurs via le shell qui est la couche interface de l'OS.
 en ce qui est de l'interface au niveau des applications l'os fournis via l'Hardware Abstraction Layer, qui est la couche logiciel permettants au systemes de communiquer avec le matériel quelque soit son origine, une facont simple et efficace pour les applications de demander et acceder au differentes ressources de la machine sans avoir a modifier leur code pour chaque materiel. au niveau des utilisateur l'Os fourni via le shell un moyen de communique à l'os soit via le terminal ou via aux interface graphiques dont nous avons l'habitude.
 exemples d'os: windows, MacOS, Android, iOS, Ubuntu(Linux), FreeBSD, xenomaiOS, etc
